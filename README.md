# Suivi Échappée Belle 2026

Page statique d'estimation des heures de passage sur l'Échappée Belle Intégrale
(vendredi 21 août 2026, 149,7 km / 11 176 m D+), à l'usage des accompagnateurs.

👉 **https://krisanselmo.github.io/suivi-eb2026/**

- horaires estimés à chaque ravitaillement, avec les points réellement accessibles en voiture
- position estimée sur la carte à l'heure qu'on veut
- recalage sur les passages relevés au fil de la course : chaque tronçon entre deux relevés
  cesse d'être une prévision, la suite est projetée sur le rythme récent
- trois replis de parcours possibles (Croix de Belledonne, col de l'Aigleton, col de Moretan)

Aucun backend, aucun build, aucune dépendance externe : tout le calcul se fait dans le
navigateur. Seules les tuiles du fond de carte viennent du réseau.

Les estimations valent ce que vaut le modèle — pente, seuil de marche, vitesse verticale,
dérive de fatigue, arrêts. Il ne connaît ni la météo, ni la nuit, ni un imprévu.
